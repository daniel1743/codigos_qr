# Secure Documents Mobile Spec

// Modified by Codex — MOBILE-NATIVE-UX-RESPONSIVE-11

## Header

Mobile header uses a compact identity row and a second action row. The back link, title, and view actions must stay inside the viewport.

## KPIs

Desktop keeps four columns. Mobile uses compact responsive cards with two columns where possible and no clipped labels.

## Documents

Desktop keeps the table. Mobile uses document cards:

- file icon
- filename
- status
- security
- expiration
- downloads over limit
- last access
- overflow actions

## Actions

Mobile actions use a viewport-capped menu. Actions are grouped by:

- Compartir
- Control
- Actividad
- Peligro

Password copy must be reachable without side scrolling.

## Create Form

The create flow must keep all upload, password, security, expiration, and download limit controls at `100%` width on phones. Password buttons must not push the input outside the screen.

## Breakpoints

Expected no-horizontal-scroll widths:

- 320px
- 360px
- 375px
- 390px
- 412px
- 430px
- 768px
